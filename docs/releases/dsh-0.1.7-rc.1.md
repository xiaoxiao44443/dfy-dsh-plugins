# DSH 0.1.7-rc.1 配套插件更新

本次更新适配 DSH 0.1.7-rc.1 的文件链接与工具准备阶段；最低支持版本仍为 0.1.7-alpha.1。

## 更新内容

- 外观插件识别新版“在侧边栏打开…”及英文文件链接标签，恢复本地文件的打开、系统定位、内置浏览器和默认浏览器菜单，同时保留旧标签识别。
- 图像生成在参数尚未生成时显示“正在准备图像生成”，继续兼容历史图片内容块。
- 交互可视化在参数尚未生成时显示“正在准备可视化”；参数就绪后继续显示创建进度。
- 组合包固定到本批经过验证的组件版本，其他组件保持原版本。

## 发布版本

| 包（@dfy-plugins/） | 版本 |
| --- | --- |
| dsh-appearance | 0.1.6 |
| dsh-image-generation | 0.1.4 |
| dsh-visualize | 0.1.4 |
| dsh-bundle | 0.1.1 |

rc.1 的兼容性检查读取插件的 peerDependencies 与客户端 inject 依赖范围；现有声明覆盖 rc.1，无需跳过校验或添加版本例外。

## 验证

- 全仓类型检查、构建及 127 项测试通过。
- 实际发布归档的入口、图标、依赖版本及完整性检查通过；7 个未改动的已发布包与 npm 校验值一致，4 个更新包通过发布预检。
- DSH 0.1.7-rc.1 的 54 个运行时导出、工具与审批行为检查通过；在隔离目录中验证独立插件和组合包安装、移除、组件启停及配置保留。

已有组合包可在桌面端插件管理中更新整包；独立安装可更新相应插件。新安装使用 `dsh plugin --profile web add @dfy-plugins/dsh-bundle@latest`，混合安装前请先按[组合包迁移说明](../../plugins/bundle/README.md)处理重复组件。
