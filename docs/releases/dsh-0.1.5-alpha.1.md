## 更新内容

- 全部 DSH 插件的安装兼容范围加入 `0.1.5-alpha.1`。外观插件此次只更新兼容声明。
- 公共资源库及归档管理兼容最新持久化快照和 V3 普通/压缩日志；媒体、视觉、可视化及生图插件使用统一读取方式。
- 媒体块使用 DSH 原生附件按钮，移除重复图片入口；兼容新版原生上传转接、混合附件、去重、时区及 PTC 图片引用。
- 生图结果兼容新版 `meta.images`、旧结果视图和 PTC 子调用，修复生成成功但没有图片预览的问题。
- Codex Bridge 兼容新版历史快照、PTC 结果和流式事件；工具经公开队列和审批服务执行，修复审批轮次、并发排队、取消与重复输出处理。
- 任务守卫保留上游请求序列标记及 pre-step 决策字段。
- 壁纸支持主界面、设置面板、右侧 Sidebar 三个区域各自选图。后两者默认无壁纸，背景不透明度为 0–100%、默认 95%；主界面保留原有“界面填充”。
- 壁纸修复无图片时背景调节失效、恢复默认按钮换行、下拉框说明间距；右侧预览框改为 2:3 纵向，显示方式仍跟随配置。替换图片覆盖对应区域旧图，各区域独立存储。

本轮配套桌面版为 [DFY DSH Desktop v0.1.5-alpha.1](https://github.com/xiaoxiao44443/dfy-dsh-desktop/releases/tag/v0.1.5-alpha.1)，内置 DSH `0.1.5-alpha.1`。旧 DFY 图片块的日志迁移准入由桌面启动器提供，插件包本身不替代该修复。

构建后需重新加载 Harness Host。完整验证范围及仍需进行的真实模型、界面验收见[兼容检查记录](../compatibility-0.1.5-alpha.1.md)。
