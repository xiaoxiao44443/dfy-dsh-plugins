# 可视化 0.1.5 与组合包 0.1.2

本次更新收紧可视化技能的触发范围，减少创建独立文件时误用对话内可视化的问题。

- `@dfy-plugins/dsh-visualize` 更新至 **0.1.5**：仅在对话内展示明显有助于解释或探索时使用。独立 HTML、SVG 动画、网站、应用页面和组件开发继续使用正常的文件或项目工作流。
- 技能简介与正文同时说明使用边界；误加载技能后，模型应返回原任务工作流，避免额外发布对话内可视化。
- `@dfy-plugins/dsh-bundle` 更新至 **0.1.2**，固定使用可视化 **0.1.5**；其他组件版本保持不变。

发布前完成全仓构建、类型检查、插件目录校验和 127 项测试，发布归档与两个新版本的 npm 预检通过。发布流程支持指定包名，本批只上传可视化和组合包，避免未改动历史包的平台换行符差异阻塞发布。

更新组合包或独立可视化插件后，重启 Harness 加载新技能。新建对话可以避免已有对话中旧版技能内容的影响。
