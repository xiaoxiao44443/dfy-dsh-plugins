# DSH 0.2.1-rc.2 配套插件更新

本批发布外观 **0.1.7**、媒体内容 **0.1.5** 和 DFY 插件组合包 **0.1.3**。

## 外观 0.1.7

- 新版 DSH 改用官方正文、代码和终端的字体与字号设置，隐藏重复的“对话字号”滑块并移除覆盖样式。
- 保留回复行距、过程行距、生成内容位置和本地文件右键菜单。旧版 DSH 保留原有字号控制；已有配置不会覆盖新版官方字号。
- 客户端热更新按实例管理样式和字体标记，避免旧实例清理新实例的资源。

## 媒体内容 0.1.5

- 适配新版用户消息渲染接口。文本、引用和有序附件复用官方渲染，历史 DFY 图片仍从原资源接口加载，敏感文本遵循官方遮挡规则。
- 修复发送消息的包装层丢失 Gateway 调用上下文的问题；原始发送与图片降级均保留调用方身份，并发等待不会串用身份。
- 继续只处理模型明确不支持图片时的降级，其他校验与授权错误保持原样。

## 组合包 0.1.3

固定包含上述两个组件版本，其他组件版本保持不变。视觉理解继续停止维护和发布。

## 更新方式

组合包用户在插件管理中更新 **DFY 插件组合包** 即可；独立安装用户更新外观和媒体内容插件。也可以在终端执行：

~~~powershell
dsh plugin --profile web update "@dfy-plugins/*" --latest
~~~

将 web 替换成实际 Profile。桌面端与插件分别发布，升级桌面安装包不会替代插件更新。

本次检查使用官方 **0.2.1-rc.2** 运行时，覆盖构建、类型、单元测试、实际导出与服务契约、独立及组合包安装、迁移和启停；Windows 界面验证包括官方字号、历史媒体、文本遮挡和客户端热更新。完整范围见 [兼容性记录](../compatibility-0.2.1-rc.2.md)。
