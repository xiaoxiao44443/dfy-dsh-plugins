# 外观插件 0.1.4

`@dfy-plugins/dsh-appearance` 从 `0.1.3` 更新至 `0.1.4`。

## 更新内容

- “每段回复前收起过程”改为在每段可见回复出现时立即生效，包括运行中的中间回复；此前需要等整轮结束。
- 最新回复之后尚未完成的思考、上下文和工具步骤继续显示。
- 后续回复到来时保留已有分组的手动展开状态；正文继续流式输出时不反复重建折叠按钮。
- 生图和可视化产出继续展示在折叠过程之外，后续文字回复出现后调整到对应回复下方。
- 保留官方 Compact 模式兼容，以及关闭折叠、卸载插件时的界面恢复行为。

## 验证

- 外观插件构建、类型检查及 15 项现有测试通过。
- 基于 DSH `0.1.5-rc.1` DOM 标记的隔离浏览器验证通过，覆盖实时回复、后续步骤、手动展开、产出位置、模式切换和卸载恢复。
- 发布归档通过官方 DSH CLI 的隔离安装、配置合成、服务端入口导入及移除验证。

## 更新方式

在桌面端“DFY 插件”列表刷新后，更新“外观”并重启 Harness；也可以执行：

```bash
dsh plugin --profile web add @dfy-plugins/dsh-appearance@0.1.4
```

使用本地 Link 安装的开发环境请更新源码并构建插件。
