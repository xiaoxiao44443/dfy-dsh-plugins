# DSH 0.2.1-rc.2 兼容性

本轮基于官方 npm `@deepseek-ai/dsh@0.2.1-rc.2`，检查从 `0.2.0-rc.2` 升级后的接口与功能重叠。插件继续以 `0.1.7-alpha.1` 为开发基线；新界面能力使用特征检测。

## 必须更新的插件

- **外观**：检测到官方 `theme.getTheme().fontSizes` 时，隐藏“对话字号”滑块，移除聊天、标题、代码和输入框的字号覆盖。字体与字号使用官方通用设置；插件保留回复行距、过程行距、生成内容位置及文件右键菜单。旧版 DSH 仍使用原有字号控制，已有 `chatFontSize` 配置保留但不会写入官方设置。热更新时，旧实例不能清理新实例的字体标记。
- **媒体内容**：官方不再导出 `projectUserText`。新版通过 `conversation.chat.user.content` Factory 渲染文本、引用及有序附件，DFY 历史图片仍通过自己的资源接口加载。这样带媒体的用户消息也经过官方敏感文本遮挡规则；旧版保留原画廊。
- **媒体内容的原生发送适配**：保留 Gateway 每次调用的接收对象及 `ctx.invocation`，包括等待队列中的并发调用；在图片能力降级时，把非 owner 调用方保留到消息来源。只扩展官方明确返回的图片能力拒绝，其他校验与授权失败原样返回。原调用不能绑定回插件安装时的根 Context。

本次适配对应外观 **0.1.7**、媒体内容 **0.1.5** 和组合包 **0.1.3**，详见 [配套更新说明](releases/dsh-0.2.1-rc.2.md)。

## 其余组件与官方功能的关系

| 组件 | 检查结论 |
| --- | --- |
| 壁纸 | 官方主题与字体配置不提供本插件的分区域壁纸、遮罩和透明度控制，保留。 |
| 归档管理 | 官方有归档与侧栏导航；本插件仍提供按项目集中管理、恢复和批量删除，保留。 |
| 图像生成 | 保留独立生图路由、参考图编辑及结果预览；官方图片输入/预览不是生图调用的替代。 |
| 交互可视化 | 官方文档侧栏可预览 HTML；本插件仍负责会话级资源发布与对话内交互展示，有部分预览用途重叠，但存储和展示位置不同。 |
| 任务守卫 | 仍提供重复工具调用/错误检测与单轮硬预算。它可能先于官方长任务目标停止当前回合，需要长任务时可调整阈值或只提醒；本轮未自动更改策略。 |
| Codex 连接 | 官方 Codex 子智能体是 DSH 调用 Codex；本插件是 Codex 通过 MCP 调用 DSH 工具、Skills 和会话，两者方向不同。 |
| 视觉理解 | 继续停止维护、构建和发布，不恢复已撤回的包。 |

官方已提供工作步骤收起时机设置，外观插件以前移除的过程折叠不会恢复。官方插件市场已支持自定义索引，桌面端 DFY 目录存在入口层面的重叠，但还承载组合包迁移、防混装及本地来源管理；暂不删除。

## 版本校验

官方优先使用 `engines.dsh`；未声明时继续检查 DSH 相关 `peerDependencies`。现有插件的范围已被实际运行时接受，不需要仅为了升级把所有包的开发依赖同步升版。新错误结果使用 `requirements`，桌面壳同时兼容旧 `peers`。

## 验证

- 全仓类型检查、构建与单元测试；导出检查覆盖实际发布运行时的 53 个具名导入，没有缺失导出。
- 实际 AgentLoop、ToolRuntime、审批、取消、持久会话重放和 SessionController 检查，无模型请求；包含两个并发远程调用各自保留身份。
- 隔离 DSH Home 中，独立安装迁移到组合包、8 个组件逐项启停、整包启停、原配置/资源/禁用选择保留。
- Windows Electron 开发版中，官方正文 14→20、代码独立字号、暗色主题、媒体历史图片/文件及敏感文本遮挡正常。
- 外观和媒体客户端在页面打开、构建监听运行时，修改可见文案并撤回，两次 HMR 后每个插件各有一个样式节点；文件输入仍隐藏；禁用后样式与自有节点清空，启用后恢复。
