# DSH 0.1.7-alpha.1 适配

## 范围

维护中的八个插件和两个公共库使用 0.1.7-alpha.1 SDK 构建，最低运行版本为 0.1.7-alpha.1。
外观 0.1.5；归档管理、媒体内容 0.1.4；壁纸、生图、交互可视化、任务守卫、Codex Bridge 0.1.3；resource-core 0.1.2；image-protocol 0.1.3。
视觉理解保留 0.1.2 历史源码，退出构建、发布和目录；桌面升级时停用旧 bundle，保留包、顺序及原配置。

## 变更

- 外观插件仅调整字号、行距和产物展示，过程折叠由官方展示模式控制。已移除逐段收起过程的设置和覆盖样式，旧折叠配置不再生效。
- 外观、任务守卫、Codex Bridge、生图迁入配置树和动态配置。旧 settings.yaml 或 settings.yaml.imported 只读导入，已有新配置优先，成功后记录按 Profile 隔离的迁移标记；失败可重试。
- 媒体块和生图附加内容改用 V4 的 plugin: 命名；工具结果使用顶层 toolCallId/isError，展示层 tool-result 不变。
- 归档恢复改用公开的 unarchiveSession；桥接改用当前 Agent 预设注册表、实时流类型、会话快照及审批接口。
- 更新前端图标、聊天翻译命名空间及客户端注入声明；壁纸移除手写旧 SDK 声明，直接检查实际 SDK 类型。
- 桌面保留 Electron 43.4.0，新包解析器和其 Worker 使用桌面已有的 --expose-internals 入口，保留官方接口校验及解析规则，不修改原生模块的版本探测；更新会话打开、通知、当前会话投影及插件启动错误解析；可选、手动安装和启动的运行时均限制在最低版本以上。
- 桌面仅扩展冻结 V2 → V3 转换器对两种既有 DFY 图片内容的严格准入，后续 V4 转换和新日志发布交给官方；源日志保留。未识别内容仍拒绝转换。
- 发布检查脚本改用当前包解析服务；跳过停更的视觉理解。
- Codex 连接与图像生成设置迁入官方插件详情页，独立安装和组合包组件均可进入；使用原生设置表单。
- 组合包及组件补齐中文名和图标；开关统一使用原生组件，下拉菜单右对齐，滑块跟随主题配色，修复深色壁纸被不透明背景遮盖。
- HTTP 路由登记到所属 Context 的 effect，支持组件及整包反复启停；发布归档验证图标体积和 locale 文件。

## 验证

- 主机和客户端类型检查、插件测试、桌面单元/集成测试。
- 实际 DSH 0.1.7-alpha.1 前端 bundle 具名导出检查。
- 实际 AgentLoop、ToolRuntime、审批、取消、FIFO、Session 回放、官方上传命令的内存集成测试，不请求模型。
- V2/V3、普通 JSONL/Zstandard 四组合：打开、写入、再次打开，转换为 V4，图片引用及原日志不变。
- 本机 Electron 43.4.0 开发版实际启动；同一 Electron 的 Node 模式下重复上述四组合迁移，包含官方包解析器和清空 execArgv 的迁移校验 Worker。
- 隔离 DSH Home 启动八个插件；外观和任务守卫旧配置导入；设置写入。
- 实际设置页确认已移除自定义过程折叠开关、DOM 标记与覆盖样式，对话过程使用官方展示模式。
- 外观和壁纸客户端修改文案、还原文案两轮热更新；各自样式节点保持单份，菜单和输入控件正常。

外部图片模型、真实 LLM 完整对话、Windows/macOS ARM64 平台仍需实际环境验收。npm 上传作为独立发布步骤执行。
