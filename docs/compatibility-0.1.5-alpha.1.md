# DSH 0.1.5-alpha.1 兼容检查与修复记录

更新日期：2026-09-09。目标为桌面端实际打包的 DSH `0.1.5-alpha.1`，macOS x64。
本轮发现的桥接审批、实时流式输出、原生图片上传转接及生图结果预览问题已完成代码修复、构建和回归。
**这不代表所有插件的真实界面及模型调用均已验收。** peerDependencies 范围只表示允许安装。

## 本轮修复

### 工具审批与排队

`ToolTurns` 通过 Agent 的公开队列进入 DSH 自己管理的 turn，在 pre-step 中调用原来的
`tools.execute` 管线。审批、拒绝、取消都经过原服务；没有自行拼接 turn 日志或关闭审批。
只有桥接控制消息时不会调用模型。原生循环在空步骤后停下，桥接会在它真正空闲后通过
公开输入接口唤醒剩余队列，保持原输入顺序。失去进程内请求身份的控制消息不会重新执行工具。

### 实时输出

桥接订阅 `agent/assistant-stream`，将实时正文/推理与最终 `assistant/message`、
`assistant/attempt` 内的压缩 stream 对齐。通过输出偏移避免在持久化时重复返回文字，
兼容旧两段游标。临时输出被放弃时返回 `outputReset`，明确要求接收方替换已累计的输出。
失败重试、取消后的部分输出和重新加载后的持久化补读均有回归。

### 原生图片上传和 PTC 引用

媒体插件接入新版 Host 的 `sessionController.prompt`。首先执行官方校验；仅当它以
`MODEL_DOES_NOT_SUPPORT_IMAGES` 拒绝，且引用适配器可用时才转交。图片继续经过
官方附件存储的 admission；混合文件凭据仍验证会话归属并采用可回滚绑定。
请求 ID、时区、steer/queue、附件顺序和重复请求去重均保留。

支持图片的模型走官方原路径；未配置可用路由时保留原错误。PTC 模式隐藏子工具的 wire
schema，因此媒体投影另取当前 Agent 的受限工具目录，供视觉/图片编辑适配器判断可用性，
不改变真正发送给模型的工具定义。

### 任务守卫

包装 pre-step 决策时保留上游全部字段，仅扩展 messages，防止丢失新版的
`startsRequestSeries`。普通提示、两条收尾路径及 reject 行为已有回归。

### 生图结果预览

用户实际生成成功后只看到工具行和文字。核对 0.1.5 的 `ToolResultNode` 后确认，
新版不再提供 `resultView`，仍保留 `meta.images`；旧组件只读取前者导致图片被忽略。
现在优先读取持久化图片元数据，兼容旧投影视图和直接图片内容，并从插件自己的结果文本
恢复不携带元数据的 PTC 子调用预览。失败结果不展示残留图片，多个来源不重复渲染。

已用该次实际会话的工具结果验证构建后组件能生成图片画廊，原图接口返回 HTTP 200，
PNG 尺寸为 1024×1536，字节数及 SHA-256 与持久化记录一致。检查未重新调用生图模型，
未修改会话日志。客户端重载后的实际点击预览仍需确认。

## 验证结果

- 本次发布前，全部 9 个插件及 2 个公共库构建、类型检查通过，全仓 125 项测试通过；重新核对 55 个运行时导入并通过以下 6 组 DSH 集成检查。
- 9 个插件、2 个公共库通过构建和类型检查。开发 SDK 仍为 `0.1.1-rc.2`，不能单凭这项证明新版兼容。
- 对照实际运行 JavaScript 核对 55 个具名导入，包含前端内置模块及 ModuleLoader 包，未发现缺失。
- 上一轮全仓 113 项测试通过；末次 Host 改动又完成对应插件的构建、类型检查和回归。
- 本次生图显示修复新增 6 项客户端渲染回归，图像生成插件共 11 项测试、类型检查和构建通过。
- 使用目标 DSH 的真实实现完成 6 组集成检查：AgentLoop 与审批允许/拒绝；并发队列与取消；Session 日志回放校验；ToolRuntime 策略与审批；Cordis 服务代理的重载清理；官方 SessionCommandController 的上传、混合文件、去重和时区校验。
- 集成测试使用内存会话和附件替身，不调用真实模型或读写用户会话。它验证调用协议，不代表实际图片服务、解码器和客户端交互已全部验收。

复现：

```bash
pnpm check
node scripts/check-runtime-exports.mjs ../dfy-dsh-desktop/build/harness-runtime
node scripts/test-runtime-compat.mjs ../dfy-dsh-desktop/build/harness-runtime
```

桥接 HTTP 测试需要允许监听回环端口；沙箱内 `listen EPERM` 是测试环境限制。
