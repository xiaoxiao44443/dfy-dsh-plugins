# @dfy-plugins/dsh-turn-guard

DeepSeek Harness 的单轮任务收敛守卫。它在模型运行过久、连续发出相同工具调用或连续得到同类错误时先注入提醒，再按设置决定是否停止当前回合。

默认策略：

- 第 12 个模型步骤、第 6 次工具调用或时间预算接近上限时提醒收敛；
- 每轮首次模型步骤注入通用执行契约：最新纠正优先、用户输入原样传递、工具和技能按明确任务动作选择；
- 先定义可观察的完成条件与最小验证方式，每次调用必须减少关键不确定性、推进所需状态或验证结果；
- 成功结果中的实际内容才算外部证据；失败、超时、空结果、未打开页面、搜索标题和模型记忆不能支撑引用或确定结论；
- 比较多个解释、实现或候选时使用同一组决定性约束，并在冲突事实出现后立即作废对应假设；
- 回答前区分已验证、合理推断和未知，决定性结论仍未验证时不得强答；
- 连续两次调用没有实质进展时停止工具循环，下一条内容直接面向用户，不再内部猜测、反复比较或补全结论；
- 工具必须按契约使用，URL、本地路径、命令和资源类型不得混用，失败后不得换个近似参数重复同一思路；
- 超过 20 个模型步骤、50 次根工具调用或 15 分钟时停止；
- 相同工具与参数或相同错误连续出现 3 次时停止；
- 工具内部的嵌套调用不重复计数；
- 达到硬限制时先封锁后续工具，并给模型一次仅用于说明原因与现状的收尾步骤；仍不收敛才强制停止；
- 停止时保留已经产生的消息、工具结果和待处理用户输入。

设置侧栏的“任务守卫”页面可以独立调整所有阈值，也可改为只提醒不停止。

```bash
pnpm --filter @dfy-plugins/dsh-turn-guard test
pnpm --filter @dfy-plugins/dsh-turn-guard build
dsh plugin --profile web add ./plugins/turn-guard
```
